# Expense Tracker

A console-based Expense Tracker built in Java.

The Expense Tracker displays a menu, and the user can choose the operation they want to perform.

## Purpose

The purpose of this project is to practice and strengthen fundamental Java programming concepts by building a practical console-based application.

Through this project, I practiced working with classes and objects, constructors, methods, `ArrayList`, loops, conditional statements, input validation, and basic object-oriented programming.

## Features

* Expense Tracker Menu
* Add Expenses
* View Expenses
* Calculate Total Expenses
* Search Expenses by Category
* Delete Expenses
* Exit the application

## Add Expenses

Users can add an expense by entering its title, amount, and category.

| Title | Amount | Category |
| ----- | ------ | -------- |
| Lunch | 150    | Food     |

## View Expenses

Users can view all expenses that have been added, along with their index, title, amount, and category.

## Calculate Total Expenses

The application calculates and displays the total amount of all stored expenses.

## Search Expenses

Users can search for expenses by entering a category.

For example:

```text
Category: Food
```

The application displays the expenses that match the category.

## Delete Expenses

Users can delete an expense by entering its index.

## How to Run

1. Clone the repository.
2. Open the project in a Java-supported IDE such as VS Code or IntelliJ IDEA.
3. Compile and run `ExpenseTracker.java`.
4. Follow the menu displayed in the console.
